# Applications

Place each independently runnable application in its own directory, such as `apps/web` or `apps/api`, once the stack is selected.

Each application owns its README, package manifest, source, tests, and example environment configuration. EmberReady uses one root npm lockfile for the workspace.

Its README must state the supported runtime and exact install, run, test, and production build commands. Add those same checks to CI in the pull request that introduces the application.
